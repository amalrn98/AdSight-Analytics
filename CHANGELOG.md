# Changelog

## 2.0.0 (web app)

- AdSight is now a web app. The Android (Expo / React Native) app was removed.
- Static Next.js site with no backend; analysis runs in a browser web worker.
- Parsers for Google, Meta, TikTok and LinkedIn data exports.
- Evidence-labelled findings (stated, observed, inferred), dashboard and
  downloadable report.
- Strict Content Security Policy that blocks outside network connections.
- CI now runs typecheck, tests and a static build.

Earlier 1.x releases were the Android app and remain in the git history.
