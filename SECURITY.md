# Security Policy

AdSight processes personal advertising-data exports. Security reports involving data exposure, unintended network activity, unsafe file handling, or report-generation vulnerabilities are especially important.

## Supported versions

Security fixes are targeted at the latest version on the `main` branch. Older revisions may not receive security updates.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in public issues or discussions.

Use GitHub's **Private vulnerability reporting** feature in the repository's Security tab when it is available. If that feature is unavailable, contact the maintainer privately through the [maintainer's GitHub profile](https://github.com/amalrn98).

Include, where possible:

- A concise description of the vulnerability.
- The affected version, commit, or file.
- Reproduction steps or a proof of concept.
- The potential impact and any relevant environment details.

Please avoid including real personal data exports, credentials, or other sensitive information in the report.

The maintainer will review the report, work to reproduce the issue, and coordinate a fix and disclosure with the reporter. Please allow time for a response before making the issue public.
